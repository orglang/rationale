# Agent instructions

## Research-document editing

- Keep each semantic explanation in one canonical section. For this document, the operation-specific contract in Section 7 is canonical for `Call`, `Link`, and `Fwd`.
- In glossaries, correspondence tables, comparison tables, and open-question lists, summarize briefly and refer to the canonical section; do not restate the same semantic explanation in slightly different wording.
- Before editing, search for all mentions of the affected concept. Update the canonical explanation and change other occurrences only when needed for consistency or to replace duplication with a concise cross-reference.
- Distinguish user-confirmed semantics from hypotheses and implementation observations. Do not infer details that the user has not confirmed or that the evidence does not establish.
- In collaborative clarification, ask one focused question at a time.
